One sentence, 169 characters, explaining the modern internet to a traveler who has just stepped out of the year 1800 — built only from things a person from 1800 already knows: a road, a post office, a library, a market square, a letter, ink. No word coined after their time, not even "internet" itself. One road joins every library, post office and market square in the world, and a letter sent from your desk reaches the far side of the earth before its ink dries.

## Run it

```sh
python3 main.py
```

Writes the sentence to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT` when set, for local verification). Pure Python standard library, no network, no working-directory use, deterministic: every run writes the same 169 bytes.
